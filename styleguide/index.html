规则摘要

  • 默认 system 跟随系统；Dark 用 data-dp-theme="dark" 重映射，禁止 invert
  • 顶栏 / 侧栏 / 画布必须跟 token，禁止写死 #fff / rgba(255,255,255,*)
  • 顶栏使用 --dp-bg-header；切换后壳层与内容须同步变色、可回切
  • Product 优先提供切换；Showcase 可保留局部深色 Hero（不等于全局 Dark）
  • 单钮循环：跟随系统 → 浅色 → 深色；存 localStorage.dp-theme
  • Dark 主色提亮；阴影改中性；正文目标 AA 对比
  • 深色底上文字必须浅：text-1/2/3/4；选中/链接用 action-fg；禁写死 Light 深色、禁用 Action 填充当字色
