# DP Design · 正反例速查

拿不准对错时打开对应节。不要在每个任务里整篇阅读。

## 色彩与组件

| ✅ | ❌ |
|----|----|
| 主按钮用 `--dp-color-action` | 业务站写死另一套蓝 / 青霓虹 |
| Product 卡片边框 + 轻或无阴影 | 重 glow、多层彩色阴影 |
| 一页一个 Primary | 一排多个实心主按钮 |
| Focus = Action 边 + 3px 环 | 去掉焦点样式 |
| Action 实心底用 `--dp-text-on-primary` | 深蓝底叠黑色字母（Avatar/Logo） |
| Avatar 默认浅底 + Action 字，或实心底 + 浅色字 | 实心蓝底 + Text 1 / 黑字 |
| 胶囊切换选中：Action 高亮底 + 白字 | 选中做成白底描边 + 深蓝字 |
| 选中底由 `.dp-segment__thumb` 滑动承担 | 给 `.is-active` 再铺一层 Action 底 / 用 Ant `Segmented` |

## Dark 文字（深色底上必须浅）

| ✅ | ❌ |
|----|----|
| 正文 `--dp-text-1/2/3/4`（Dark 已是浅色） | 写死 `#1d2129` `#4e5969` `#020c1a` `#000` |
| 侧栏选中 / 链接 / 图标 `--dp-color-action-fg`（`#d2d6ff`） | 选中字用 `--dp-color-action`（`#6b74f2`）发暗 |
| 主按钮深 Action 填充 + **白字** | 主按钮浅紫底 / 或深蓝字叠深蓝底 |
| 浅底 Tag/徽章用近白或 `action-fg` | Tag 蓝底 + 同色深蓝字 |
| 扫一遍：深底上无深灰/深蓝字 | 只改了按钮、漏了侧栏/链接/caption |

## 嵌套圆角（同心）

| ✅ | ❌ |
|----|----|
| 主卡 / 面板用 `--dp-radius-container`（16） | 主卡仍用 8，页面偏硬 |
| 子 = max(0, 父 R − P)，再下取阶梯 | 父卡与内层结果区同写 16 或同写 8 |
| 父 16 + padding 8 → 内层 **8** | 内层仍用 16 → 圆角处缝变窄 |
| 父 16 + padding 24 → 内层 **0** | 大内边距仍给内层 8/16 |
| Pill Chip / 开关 / 胶囊切换保持 pill | 把 Chip 或胶囊强行改成公式直角（无需） |

## 顶栏 · 侧栏 · 页脚

| ✅ | ❌ |
|----|----|
| Logo 在整个窗口左上角（Product 倒 L：侧栏通高；Showcase：顶栏最左） | 顶栏通栏、Logo 放在侧栏顶落到顶栏下方 |
| 功能入口无框（会话/智能体/对话/工作流） | 功能入口做成带边框按钮 |
| 主题 / 语言等模式切换用胶囊；颜色默认跟随系统 | 单钮循环 / 矩形 tab / 「深」「浅」单字 |
| Showcase 分区页脚；Product 无页脚或单行版权 | 控制台塞满页脚链接矩阵 / 页脚 Primary 大按钮 |
| 下载用 `action-download` + 可选文案 | 仅灰字「下载」、无图标且过浅 |

## 空态 / 反馈

| ✅ | ❌ |
|----|----|
| 空态线型图标 48–64 → 标题 → 说明 → 一主按钮 | 只有一句「暂无数据」无行动 |
| 空态用图标库（inbox / search / lock…） | 引用 `illustrations/dp-illust-*.svg` 存档图 |
| 删除用 Modal 确认 | 删除仅 Toast |
| Toast 短结果 | Toast 写长篇说明 |
