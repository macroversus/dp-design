# Logo 资源（占位）

正式 Logo 文件待品牌 / 设计提供后放入本目录。

## 约定文件名（到位后）

| 文件 | 用途 |
|------|------|
| `dp-logo-color.svg` | 浅色底默认 |
| `dp-logo-white.svg` | 深色底 / Hero |
| `dp-logo-mark.svg` | 仅标记（侧栏折叠等） |
| `dp-logo-color.png` | 位图备用（@2x） |

## 使用规则（摘要，详见规范 §13）

- 不改品牌色、不拉伸、不加阴影/描边特效
- 最小可读宽度：横版 Logo ≥ 96px；标记 ≥ 24px
- 与背景保持足够对比；深底用白色版本
